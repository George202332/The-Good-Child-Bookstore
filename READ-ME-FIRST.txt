BATCH 6, version 2 (replaces print fix 5; includes it; now also includes the decision buttons file the review page needs). No database change. Staging only.

1. Copy the app, lib and tests folders from this zip into your bookstore folder (Replace).
2. In PowerShell inside the bookstore folder:
     git checkout staging
     git add .
     git commit -m "Batch 6: publish page, My Books table, separate editing, admin review sections, mockups without shadows"
     git push origin staging
3. Wait for staging to be Ready.

STAGING TEST CHECKLIST
 A. Submit a New Title: the two tabs read "Publish eBook/Audiobook" and "Publish Print Book". The buttons at the bottom: Save Draft, Publish (and Delete Book on a saved book).
 B. Press Publish on a complete book: you land on a page "Your ... Was Successfully Published ... submitted for review for approval", then My Books after about 5 seconds (or press Go to My Books).
 C. My Books: 15 books a page with arrows under the table; columns Title, Author, Category (the real category, not the genre), Units Sold, Royalty, eBook, Audiobook, Paperback, Hardcover. No Status or Edit column. Published formats show the number sold with "Published" beneath (0 if none); anything else says "Unpublished".
 D. Hover a book row: "Edit eBook/Audiobook" and "Edit Print Book" appear. Each opens only that edition, with no other tab. Saving a print edit never touches the eBook, and the other way round.
 E. Mockups (author preview and product page, after choosing Paperback or Hardcover): no shadow under the books and no reflection. Old product-page mockups redraw the next time they are opened.
 F. Admin: open a book posted by an author in Book Management > review. There is a section "eBook / Audiobook" (manuscript preview in PDF/EPUB/MOBI plus an audiobook player) and a section "Print Book" (PDF preview and print details), each with its own Approve / Attention / Suspend / Withdraw. In Book Management a yellow banner and a "Needs review" tag mark books waiting.
 G. Print: Autofill from eBook copies details and cover only, never the eBook file; checks show moving dots while running.
